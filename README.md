# SIIT Roadmap

> **เว็บหางานบอกว่ามีงานอะไร — ของเราบอกว่าจะไปถึงงานนั้นได้ยังไง**
> และต่างจากเว็บหางานตรงที่เราไม่เชื่อสิ่งที่ผู้ใช้กรอกอย่างเดียว **เราอ่านจากผลงานจริงของเขา**

เว็บสำหรับ **นักศึกษา SIIT ที่ยังไม่รู้ roadmap ไปถึงสิ่งที่ตัวเองต้องการ**
หน้าแรกรับทั้งคนที่รู้ตัวเองแล้วและคนที่ยังไม่รู้ แล้วสองฝั่งมาบรรจบที่ Roadmap เดียวกัน

---

## รันยังไง

ต้องเปิดสองอย่าง ไม่ต้องติดตั้ง Postgres, Docker หรือ LLM API key

```bash
make setup     # ครั้งแรกครั้งเดียว — venv + deps + ดาวน์โหลด O*NET + รันท่อข้อมูล
make backend   # พอร์ต 8000 · เอกสาร API ที่ /docs
make frontend  # พอร์ต 3000
make test      # 133 เทสต์ ต้องผ่านหมดก่อน push ทุกครั้ง
```

ถ้ายังไม่มี `make` ดูคำสั่งดิบใน [`Makefile`](Makefile)

## 🟢 อะไรจริง · 🔴 อะไรยังไม่จริง

พูดเองก่อนกรรมการถาม — และอย่าเผลอพูดเกินนี้บนเวที

| ส่วน | สถานะ |
|---|---|
| เครื่องยนต์ roadmap (gap · frontier · rank · path · จับคู่ทรัพยากร) | 🟢 **จริง** 133 เทสต์ครอบ |
| ตัวจับคู่อาชีพจากแบบทดสอบกิจกรรม | 🟢 **จริง** ผ่านเทสต์กู้คืน 8/8 |
| โครงทักษะ 73 ตัว · DAG 105 เส้น | 🟢 **จริง** 47 ตัวอ้างกลับไป O*NET ได้และมีเทสต์ตรวจ |
| กิจกรรมในงาน 41 มิติ + โปรไฟล์ของ 8 อาชีพ | 🟢 **จริง** มาจาก O*NET ตรง ๆ |
| รับ CV 4 ทาง (PDF · ข้อความ · GitHub · LinkedIn) | 🟢 **จริง** — GitHub ยิง API จริง |
| span ที่ชี้กลับไปที่บรรทัดใน CV | 🟢 **จริง** มี guard ทิ้งทุกอันที่หาไม่เจอในต้นฉบับ |
| **ตัวสกัดทักษะจาก CV** | 🔴 **จับคำสำคัญ ไม่ใช่ LLM** — *"ทำให้สองระบบคุยกัน"* จับไม่ได้ ต้องเขียนว่า *"API"* |
| **requirement ของ 8 อาชีพ** | 🔴 **เราเขียนเอง ยังไม่ได้มาจากประกาศงานจริง** `posting_count = 0` ทุกอาชีพ |
| **ชื่อวิชาในหลักสูตร** | 🔴 **ชื่อทั่วไป ไม่ใช่หลักสูตร SIIT จริง** จงใจไม่ใส่รหัสวิชาปลอมที่ดูเหมือนจริง |
| **หน้าเว็บทั้งหมด** | 🔴 **ยังไม่มี** |

`GET /api/health` และ `GET /api/meta` รายงานสถานะพวกนี้ตามจริงเสมอ — อย่าไปแก้ให้มันโกหก

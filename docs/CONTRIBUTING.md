# กติกาการทำงานร่วมกัน

---

## ตั้งเครื่องครั้งแรก

```bash
make setup
```

ทำสามอย่าง: สร้าง venv + ลง deps · ดาวน์โหลด O*NET (106 MB ครั้งเดียว) · รันท่อสร้างข้อมูล
ถ้าค้างตรงดาวน์โหลด รันซ้ำได้ ไม่พัง

```bash
make backend    # :8000  · เอกสาร API ที่ /docs
make frontend   # :3000
make test       # 133 เทสต์
```

---

## สาขาและการส่งงาน

```
main                    ต้องรันได้และเทสต์เขียวเสมอ · ห้าม push ตรง
feat/roadmap-page       ตั้งชื่อตามงานที่ทำ
fix/span-offset         แก้บั๊ก
data/job-postings       งานข้อมูล
```

1. แตกสาขาจาก `main`
2. ทำงาน · commit ย่อย ๆ ได้
3. `make test` ให้เขียวก่อน
4. เปิด PR · ให้คนที่งานต่อกับเราอ่านอย่างน้อย 1 คน
5. merge แล้วลบสาขา

**ข้อความ commit เขียนเป็นภาษาไทยได้** ขอแค่บอกว่า*ทำอะไร* ไม่ใช่ *แก้ไฟล์ไหน*

```
✅ หน้า roadmap แสดงสถานะ in_progress แยกจาก locked
❌ update roadmap page
```

## แต่ละคนเป็นเจ้าของไฟล์ของตัวเอง

ดูตาราง "เป็นเจ้าของ" ใน [`TEAM.md`](TEAM.md) · จะได้ไม่ชนกันตอน merge

**ไฟล์ที่ทุกคนใช้ร่วมกัน แก้ได้แต่ต้องบอกในกลุ่มก่อน**

| ไฟล์ | ใครดูแล | ทำไมต้องบอก |
|---|---|---|
| `frontend/lib/api.ts` | 🅲 | ทุกหน้าเรียกผ่านตัวนี้ |
| `frontend/components/**` | 🅲 | ทุกหน้าใช้ |
| `backend/app/api.py` | 🅳 | ฝั่งหน้าเว็บต่ออยู่ |
| `backend/app/seed/**` | 🅴 | เปลี่ยนข้อมูลแล้วเทสต์อาจแดง |

## 🔴 ห้ามทำ

| ห้าม | เพราะ |
|---|---|
| **push `.env` หรือ API key** | มีใน `.gitignore` แล้ว แต่ถ้าหลุดต้อง revoke key ทันที |
| **push CV ของผู้ใช้ทดสอบ** | ข้อมูลส่วนบุคคล — `data/uploads/` ถูก ignore ไว้แล้ว |
| **push `pipeline/cache/`** | 106 MB · ดาวน์โหลดใหม่ได้ด้วย `make onet` |
| **แก้เทสต์ให้ผ่านโดยไม่แก้โค้ด** | เทสต์ 5 ข้อในหัวข้อถัดไปคือกติกาของผลิตภัณฑ์ ไม่ใช่รายละเอียดทางเทคนิค |
| **เขียน scraper ดึงประกาศงานอัตโนมัติ** | ผิด ToS ของเว็บหางานส่วนใหญ่ · เก็บมือ 30–50 อันพอ |
| **ทำให้ `/health` หรือ `/meta` รายงานว่าอะไร ๆ จริงกว่าที่เป็น** | เราจะพูดบนเวทีตามที่โค้ดบอก โค้ดต้องไม่โกหกเรา |

## เทสต์ที่ห้ามทำให้แดง

รัน `make test` แล้วถ้าแดงที่ข้อพวกนี้ **แปลว่าโค้ดผิด ไม่ใช่เทสต์ผิด**

| เทสต์ | คุมอะไร |
|---|---|
| `test_every_span_is_really_in_the_document` | หลักฐานที่อ้างต้องมีอยู่จริงใน CV |
| `test_guard_throws_away_invented_text` | ถ้าตัวสกัดแต่งข้อความขึ้นมา ต้องถูกทิ้ง |
| `test_pending_skills_do_not_count_until_confirmed` | ผู้ใช้ต้องยืนยันก่อนถึงนับ |
| `test_roadmap_separates_cv_evidence_from_self_reported` | ทักษะสองชนิดห้ามรวมกัน |
| `test_first_actionable_step_is_the_one_rank_chose` | ก้าวที่กดได้ = ก้าวที่ระบบเลือก |
| `test_recovery_simulated_user_gets_their_own_career_first` | แบบทดสอบต้องไม่ให้คำตอบเดียวกับทุกคน |
| `test_every_step_has_at_least_one_way_to_reach_it` | ก้าวที่ไม่มีทางไปถึง = ก้าวที่กดไม่ได้ |
| `test_health_reports_what_actually_loaded` | ระบบต้องรายงานสถานะตามจริง |
